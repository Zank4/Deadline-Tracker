Vibe code vui vẻ dùng cho mục đích cá nhân

Web đơn giản chỉ sử dụng local storage:
- Cần sử dụng cùng trình duyệt và cùng profile để giữ trạng thái.
- Mở bằng trình duyệt hoặc thiết bị khác sẽ có dữ liệu riêng.
- Dữ liệu vẫn còn khi refresh, đóng/mở trình duyệt hoặc restart máy.
- Nếu xóa dữ liệu trang web / site data / localStorage thì các deadline đã tạo sẽ bị mất.
